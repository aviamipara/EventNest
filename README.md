# EventNest - Event Management System

**EventNest** is a premium, modern Event Management System built for a Final Year Project. It features a high-quality design, dynamic event rendering, and a booking simulation.

## 🚀 How to Run

### Method 1: Direct Open (Simplest)
1. Navigate to the project folder.
2. Double-click on **`index.html`**.
3. The website will open in your default browser.

### Method 2: VS Code Live Server (Recommended)
If you are using VS Code:
1. Install the "Live Server" extension.
2. Right-click on `index.html`.
3. Select "Open with Live Server".

## 📂 Project Structure
- **`index.html`**: Home/Landing page.
- **`events.html`**: Dynamic event listings with filters.
- **`services.html`**: Services and pricing.
- **`contact.html`**: Contact form.
- **`booking.html`**: Booking flow.
- **`assets/`**: Contains CSS, JS, and Images.

## ✨ Features
- **Dynamic Content**: Events are loaded from JavaScript (`assets/js/main.js`).
- **Premium Design**: Custom CSS with glassmorphism and neon effects.
- **Responsive**: Works on mobile and desktop.
- **No Dependencies**: Pure HTML, CSS, and JS.
